Brand book vs site

Each pair shows the brand-book page concept (left) beside the implemented site at the same state, captured 16 October 2026 at 1440px desktop and 390px phone. Images are in qa/.

Main timeline

Same composition: era bar with planned widths, family lanes, portrait bubbles at the start of each life, evidence knots, the “raised by Lib and Thomas, from 1876” link and the marriage link appearing only for the selected person, and the docked panel. The site adds the long shallow map above it, a Meeting and community lane, and fading ends where a life’s dates are not in the archive (the book drew those as arrows).

Family tree

Same layout and portraits, now drawn from content.json.relationships. Selecting a person in any view selects them here. The site adds a “Centered” layout, which is the default on phones.

Map

The book’s map was a style study of an invented place. The site uses the same style for a schematic of the real geography, from Germantown west to Drumore and Fulton. It is labeled Drawn, keeps direction and order only, and draws no exact pins. The map zooms to the selected person’s, event’s or place’s locations.

One person’s story

Same structure: scene rail with evidence marks and the current scene highlighted, Walnut date line and Reported chip, Gelasio title and prose, quotation, original objects with provenance tabs, sources and the return pill. The site uses Codex’s five reviewed scenes and adds “Other dated moments” for events not yet written as scenes.

Phone

Story first, with the return pill pinned bottom-left. The timeline runs down the screen with lifeline threads at the left, and the family view centers on one person. The source viewer shows the page with its transcription. The bottom bar holds Timeline, Family, Places and Stories.
