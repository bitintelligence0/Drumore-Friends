# Google Drive agent guide

This document mirrors the operating rules saved in the shared Google Drive folder. It applies to coding agents, research agents, and computer use agents working for any contributor.

## Shared location

**My Drive / Personal / Family / Drumore Friends**  
Folder: https://drive.google.com/drive/folders/1SzyWjGO0M7-qMsQh1l2XE6I3Va_5MRqy

Google Drive is the shared source of truth for source material and collaborative research. GitHub is the source of truth for website code and structured publishing records.

## Folder behavior

- `01 Source Archive`: preserved evidence from the Facebook capture. Read and cite it. Do not rename, overwrite, reorganize, or delete existing files.
- `02 Contributor Inbox`: additions from people or agents. Create one dated folder per intake and include a README with contributor, source, date received, description, known people or places, rights status, privacy limits, and unanswered questions.
- `03 Working Research`: research notes, comparisons, transcriptions, and review material. Label drafts and identify sources.

## Agent rules

- Never make the folder or a source file public.
- Never change sharing, delete material, or move source evidence without explicit human approval at the time of the action.
- Never treat a filename, face match, social tag, caption, or generated transcription as verified identity or history.
- Never treat possession as permission to publish. Record ownership, permission, caption, and credit separately.
- Preserve archive IDs and original source links. Do not reuse an ID.
- Keep historical dates separate from Facebook posting dates and retain uncertainty and conflicting readings.
- Put new material in the Inbox. Do not silently merge it into the preserved archive.
- Do not copy the raw archive into GitHub. Add only intentionally selected web derivatives with a matching structured image record and appropriate rights status.
- Record meaningful research conclusions in the relevant GitHub record through a reviewed pull request. Link the Drive evidence by stable archive ID rather than a contributor-specific local path.
- Leave a short handoff note naming files reviewed, records affected, open questions, and any actions that still require a human.
